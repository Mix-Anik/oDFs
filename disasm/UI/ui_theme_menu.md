# ui QVM — DeFRaG in-game settings menu & theme cvars (`df_ui_*`)

Found by following the `df_ui_*` strings in `ui.dis`:
- `0xa7e2` (called from `0xb4b2`) and `0xa847` (called from `0xb4be`, `0xb54f`) register/refresh the theme cvars: `df_ui_CustomMenu`, `df_ui_DisplayCVarName`, `df_ui_TextColorLabel`/`Value`/`Disabled`/`Medium`/`Big`/`Highlight`, `df_ui_PulseColor`, `df_ui_ListbarColor`, `df_ui_StatusColor`, `df_ui_CursorColor` — the colour cvars take `".r .g .b .t"` (four floats; empty = the stock ID colour). The same functions mask a flags word with `~0x5001` on two table entries (cvar-flag handling of the `ui_*` mirror table, details not decoded).
- `0xb59f` builds the **description table** of the DeFRaG "Mod settings" menu — each row is a (help text, cvar) pair. Strings show the settings it exposes (with defaults shown in the help text): `timescale` (cheats only, in-game), `com_maxfps`, `sv_fps`, `g_synchronousClients` (default On), `pmove_fixed`, `pmove_msec` (8..33, default 8), `cl_avidemo`, `cl_freezeDemo`, `cg_thirdPerson`, `cg_thirdPersonRange` (default 40), `cg_thirdPersonAngle`, `cg_cameraOrbit`, `cg_cameraOrbitDelay` (default 50), then the `df_ui_*` theme cvars above. Help for the theme: "Custom Menu on/off (Default = On with status hint colors)", "Display CVar Name in menu (Default = On)", "Cursor Color … (default = 0.50 0.80 1.00 1.00)".
- `df_country` (set to `"CountryHere"` by the ui cvar-default block at `0x944`, see `ui_cvar_table.md`) is read by the player-settings screen (4 sites, `ui.dis` ≈ 60320/60635/67059).
Interpretation: pure client-side menu plumbing (no server input). The menu text confirms the intended defaults for `pmove_msec` (8), `g_synchronousClients` (On) and `cg_thirdPersonRange` (40) on the client side.
oDFs: no impact (players run the original DeFRaG ui; oDFs ui.qvm is unusable with the proxymod engine, see memory).
