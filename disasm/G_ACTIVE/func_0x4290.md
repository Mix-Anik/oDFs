# func_0x4290 — SetLGKnockback

**Address:** `0x4290`  
**Stack frame:** `enter 0x10`  
**Called from:** func_0x421b (`0x421b`), also `0x20d2d`  
**Args:** `(playerState_t *ps, int lg_knockback_flag)`

---

## Purpose

Sets or clears bit `0x1000` in `ps->stats[12]` (`STAT_DEFRAG_FLAGS`) based on the `df_lg_Knockback` cvar value.

---

## Pseudocode

```c
void func_0x4290(playerState_t *ps, int lg_knockback_flag) {
    if (lg_knockback_flag != 0)
        ps->stats[12] |=  0x1000;   // DFLAG_LG_KNOCKBACK — set
    else
        ps->stats[12] &= ~0x1000;   // clear
}
```

---

**Note:** Also called from `0x20d2d` — **identified this pass**: `0x20d2d` is
`Pickup_Weapon` (weapon-item pickup handler), which calls this function only
when the picked-up weapon is `WP_LIGHTNING` (6). Fully decoded, confirmed to
contain zero floating-point instructions and zero references to `ps.velocity`
or the `df_promode` cache — unrelated to knockback/velocity. See
[func_0x20d2d.md](func_0x20d2d.md).

**Consumer fully decoded — see [LG_Knockback.md](LG_Knockback.md).** The
`DFLAG_LG_KNOCKBACK` bit this function sets does not gate a simple velocity kick; it
gates whether Lightning Gun hits also spawn an invisible splash-damage "phantom
rocket" at the beam impact point, detonating through the standard rocket
splash/knockback pipeline.
