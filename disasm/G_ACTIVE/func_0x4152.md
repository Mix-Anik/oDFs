# func_0x4152 — DeFRaG input state tracker

**Address:** `0x4152`  
**Stack frame:** `enter 0x30`  
**Called from:** PmoveSingle (`0x8331`) at instruction `0x8335` — first call made in PmoveSingle  
**Args:** `(pmove_t *pm)`

---

## Purpose

Builds a bitfield of the player's current input state and stores it in `ps->stats[13]` (`STAT_DEFRAG_INPUT`). Runs at the top of every `PmoveSingle` call so client prediction always carries the current key state. The DeFRaG client reads `stats[13]` to drive the key-indicator HUD overlay.

---

## Pseudocode

```c
void func_0x4152(pmove_t *pm) {
    pm->ps->stats[13] = 0;

    if (cmd.forwardmove > 0)  stats[13] |= 0x001;   // forward
    if (cmd.forwardmove < 0)  stats[13] |= 0x002;   // backward
    if (cmd.rightmove < 0)    stats[13] |= 0x008;   // strafe left
    if (cmd.rightmove > 0)    stats[13] |= 0x010;   // strafe right
    if (cmd.upmove > 0)       stats[13] |= 0x020;   // jump
    if (cmd.upmove < 0)       stats[13] |= 0x040;   // crouch
    if (cmd.buttons & 0x1)    stats[13] |= 0x100;   // BUTTON_ATTACK

    // func_0x4122: returns 1 if abs(forwardmove)==64 OR abs(rightmove)==64
    if (func_0x4122(pm))      stats[13] |= 0x200;   // diagonal movement cap
}
```

---

## Bit layout of stats[13]

| Bit | Constant | Condition |
|-----|----------|-----------|
| 0x001 | `DINPUT_FORWARD` | `cmd.forwardmove > 0` |
| 0x002 | `DINPUT_BACKWARD` | `cmd.forwardmove < 0` |
| 0x008 | `DINPUT_LEFT` | `cmd.rightmove < 0` |
| 0x010 | `DINPUT_RIGHT` | `cmd.rightmove > 0` |
| 0x020 | `DINPUT_UP` | `cmd.upmove > 0` |
| 0x040 | `DINPUT_DOWN` | `cmd.upmove < 0` |
| 0x100 | `DINPUT_ATTACK` | `cmd.buttons & BUTTON_ATTACK` |
| 0x200 | `DINPUT_DIAGONAL` | `abs(fwd)==64 \|\| abs(right)==64` |

Bits 0x4 and 0x80 are not set by this function.

---

## func_0x4122 — diagonal cap check

**Address:** `0x4122` — called only from func_0x4152  
**Returns:** 1 if `abs(forwardmove) == 64` OR `abs(rightmove) == 64`; 0 otherwise.

In Q3/DeFRaG, diagonal movement at full speed caps each axis at exactly 64. This bit distinguishes diagonal strafe from pure-axis or no movement.

```c
int func_0x4122(pmove_t *pm) {
    if (abs(cmd.forwardmove) == 64) return 1;
    if (abs(cmd.rightmove)   == 64) return 1;
    return 0;
}
```
