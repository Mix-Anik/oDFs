# DeFRaG cgame acceleration meter (`df_accel_*`)

Structural map of the cgame code behind the nine `df_accel_*` cvars ([cgame_cvar_table_full.md](cgame_cvar_table_full.md)): `Draw`, `FontSize`, `Mode`, `Output`, `OffsetX`, `OffsetY`,
`Scale`, `AdjustMaxSpeed`, `HistoryResetSpeed`. Consumers were found by resolving each cvar's storage address from the table (`vmCvar` base + `0xc` = `.integer`) and
searching `cgame.dis` for those addresses — only these six functions read them:

| Function | Reads | Role (from calls, constants and strings; bodies not fully decoded) |
|---|---|---|
| `0x15ff4` (called from `0x79ac`, the 2D draw pass) | `Draw`, `Mode` | **Entry point** (`CG_DrawAccel`-shaped): if `Draw` (via helper `0x8f3a`) is off, return; `0x15f83()` is an availability gate (its body calls two traps and reads a global at `0x12a2b4`; returns 0 to skip drawing); then `Mode == 0` → `0x15e45`, `Mode != 0` → `0x15d20`. |
| `0x15e45` (467 lines) | `OffsetX`, `OffsetY` | **Mode 0 draw**: positions relative to the screen (globals `0x114050`, `0x125f04`, `0x125df4`), calls the meter computation `0x15a60`, then several draw calls. |
| `0x15d20` (476 lines) | `FontSize`, `Mode`, `OffsetX`, `OffsetY` | **Other modes draw**: text glyphs `"O"` and `"+"` with the constants `320.0f`/`240.0f` (`0x43a00000`/`0x43700000`, the screen centre), i.e. a centred marker/graph; also calls `0x15a60`. |
| `0x15a60` (625 lines) | `AdjustMaxSpeed` | **Per-frame computation**: float-heavy (`0x43340000` = 180.0, `0x40490fdb` = π → angle conversions, `sqrt`/`atan2`-style traps), writes results into a block at `0x125bd4`, calls `0x1584c`. |
| `0x1584c` (448 lines) | `AdjustMaxSpeed`, `Output` | **Percentage + optional log output**: `percent = value * 100.0f` (`0x42c80000`) clamps; when `Output` is set, prints the debug lines `"SPEED:   ^%istart ^7= ^%i%8.3f ^%ispeed ^7= ^%i%8.3f ^%imax ^7= ^%i%8.3f\n"` and `"PERCENT: ^%iaccel ^7= ^%i%8.3f ^%ispeed ^7= ^%i%8.3f\n"` (start/current/max speed and acceleration vs. speed, each with a colour index). |
| `0x164d6` (called from `0x15c24`) | `HistoryResetSpeed` | History reset: when speed falls below the cvar the stored history (`0x125ac4`) is cleared. |

What the meter measures (from the printed names): **start speed, current speed, max speed** and the **percentage of the maximum possible acceleration** achieved over a frame.
`Scale` (cvar) is read by no function in the list above, so its consumer is unlocated (may be reached through a different access path).

## oDFs
Nothing ported — oDFs's cgame has none of these cvars or functions (see the cgame cvar table doc). The numeric details (exact formula for the accel percentage, how `Mode` selects
between the two draw paths, colour thresholds) need a full decode of `0x15a60`/`0x1584c`.


## Iter 38 — full decode (pseudo-C of every function in `accel_meter_qdec.txt`, produced by `disasm/tools/qdec.py`)
**Globals** (cg_t base `0xcfcc8`): `cg.snap` `0xcfcec`, `cg.demoPlayback` `0xcfcd0`, `cg.time` `0xea11c`, `cg.predictedPlayerState` `0xea13c` (`+0x20` velocity, `+0x2c`.. ), `0x129864` = "use predicted ps" switch (`!= 0` => `predictedPlayerState`, else `snap->ps`), cvars: `df_accel_Draw` `0x126344`, `Mode` `0x126124`, `OffsetX` `0x125f04`, `OffsetY` `0x125df4`, `FontSize` `0x126234`, `Output` `0x126014`, `HistoryResetSpeed` `0x125ac4`, `AdjustMaxSpeed` `0x125bd4`, `Scale` float `0x125d60` (abs value = bar scale, used by `0x15bd7`), `df_chs2_FontColor/LabelColor/FontTransparency/FontShadow` `0x127554/0x127334/0x127440/0x127664` (HUD text colours shared with the CHS2 widget), `cg_drawCrosshair` `0x16b54`, `cg_crosshairSize` `0x163e0` (value), `cg_crosshairX/Y` `0x16604/0x164f4`, `pmove_msec` `0x12b94` (int), data: `0x23d8` 750.0, `0x23dc` 25.0, `0x23e0` 600.0, colours table `0x4144` (10 x RGBA stride 16: black, red, green, yellow, blue, cyan, magenta, white, orange, grey) used for `^N`-style indices, crosshair shader table `0x114050`.
**Entry** `0x15ff4` (from the 2D pass `0x79a7/0x79ac`): returns unless `df_accel_Draw` passes `0x8f3a` (arg 0..4 selects when the meter is allowed: 0 never, 1 always, 2 = not-demo-and-self, 3 = demo-or-other, 4 = always…) and the gate `0x15f83` (needs a non-zero speed or a followed client; uses `0x13e70` = find the first client slot with `connected==2 && ...`), then `Mode == 0` -> `0x15e45` else `0x15d20`.
**Per-frame driver** `0x15c24` (called from the draw pass before the draw): picks `pos/vel/viewangles` from `snap->ps` (`+64`,`+76`,`+196`) or from the predicted ps (`0xea150`, `0xea15c`, `0xea1d4`) depending on `0x129864`; for a followed client uses the interpolated entity data (`0x13e70`, `0x13eb1` = velocity from the last two entity positions); `grounded = 0x1558d(pos)` (box trace 5 below: mins/maxs from data `0x23e4/0x23f0`, mask `0x2010001`); `wish = 0x156f7(&wishdir, &viewangles)` (usercmd forward/right from key state via `0x155d2` (`0x85c0` = key mask tests 1,2,8,16 of stats[13]/snap) or `trap_GetUserCmd`; scale `0x15658` = `speed*max(|f|,|r|,|u|)/(127*sqrt(f²+r²+u²))`; AngleVectors `0x31c8d`), `wishspeed = |wishdir| * scale`; `0x15a60(pos, vel, wishdir, wishspeed, 1.0, grounded)`; start/stop logic around `0x2a9718`; then the jump history logger `0x16513` (separate subsystem: `0x1607e` ground test, `0x1648f/164a9/164bc/164cf` event handlers writing `0x2a9578..`, uses `df_accel_HistoryResetSpeed` via `0x164d6`).
**Compute `0x15a60`** (keeps state at `0x2a9584..0x2a9730`): on ground (`la8 != 0`) resets the accumulators (`0x2a971c = 0x2a9720 = 0`, flushes the SPEED/PERCENT log via `0x1584c(1)` once); in the air: first frame stores start time/pos/vel (`0x2a9724`, `0x2a9728`, `0x2a9734`), start speed; then each frame `dt = 0x8e4a(&lastTime, mode)` (ms*0.001 from `cg.time` delta, or from `trap_Milliseconds` scaled by `timescale` when `mode==0`), `accel = a4 * dt * wishspeed` hmm — precisely `l28 = (la4 * dt) * l24` where `l24` = `0x15774()` (cmd scale * `snap->ps.speed`, or ps.speed when no key state), `l3c = (l24 - l28) / |v|` clamped to acos domain: `theta = acos(l3c)`; velocity rotated: new speed `l2c = |v| (+ ((|v| - 750)/25) * dt when AdjustMaxSpeed)`, `v = (l28*cos th, l28*sin th)` added; angles accumulated with `0x15961` (relative angles between velocity, wishdir and view: `acos` of normalised dot products, sign fixed by `0x15579`, results in `0x2a971c`(right) / `0x2a9720`(left) = the two opposing angle offsets in degrees).
**Percent `0x1584c`**: `start = |v0|`, `cur = |v1|`, `max = |v_max|`; `ideal = 0x157f8(start, dtMs)` = `sqrt(start² + a*(2*320-a)... )` — closed form for the best possible speed after `dt` of full-accel strafing (`a = 320*0.001*pmove_msec`, `l18 = a*(2*320 - a)`, `sqrt(start² + l18 * (frametime / pmove_msec))`); when `AdjustMaxSpeed==0` `max = ideal`; `percentSpeed = 100*(cur-start)/(max-start)`, `percentAccel = 100*cur/max`; stored in `0x2a9728..0x2a9760`; with `df_accel_Output` and not mid-flight prints the `SPEED:`/`PERCENT:` lines.
**Draw mode 0 `0x15e45`**: crosshair shader `0x114050[df_crosshair % 10]`, size `cg_crosshairSize` (both axes), position = screen-centre via `CG_AdjustFrom640` with `cg_crosshairX/Y` + `df_accel_OffsetX/Y`; if an offset is set it first draws a plain crosshair copy at the unmoved position, then draws the crosshair a second time shifted horizontally by `0x15ceb(x, 0x15bd7())` = `x + (-leftAngle | rightAngle) * scale` (the angle with the smaller magnitude), where `0x15bd7` returns `|Scale|` (reduced by `speed/600` while decelerating (`Scale < 0` and speed != 0)); i.e. the crosshair slides to show the strafing offset.
**Draw other modes `0x15d20`**: glyphs: `Mode 1` draws the string `"O"` and `Mode 2` draws `"+"` at the shifted x (colour `colours[(df_chs2_LabelColor... % 10)]` with alpha `df_chs2_FontTransparency`, size `df_accel_FontSize`, shadow `df_chs2_FontShadow`) and always the fixed `"+"` (`0xc350`) at the unshifted position, centred on `(320 + OffsetX - FontSize/2, 240 + OffsetY - FontSize/2)`.
**oDFs**: NOT ported yet (this iteration: decode only). Port plan: `cg_dfaccel.c` with the compute state machine (`0x15a60`, `0x15961`, `0x1584c` percent) + mode 0/1/2 draw; skip the jump history logger `0x16513` family and the SPEED/PERCENT debug log unless wanted.


## Iter 39 — PORTED (`code/cgame/cg_dfaccel.c`) + corrections to the iter-38 narrative
Verified while porting (use `qdec.py`; frame args are `l(frame+8+4k)`): `0x15a60(pos, vel, wishDir, wishSpeed, mult, grounded)`; the 'Milliseconds' branch at `0x15a79` is dead code (always `cg.time`); `0x129864` is the CVAR **`df_chs_UsePredicted`** (default 1; selects predictedPlayerState vs snap->ps for pos/vel/angles and for the key mask); `0x125ce0` (decimal 1203424) is `df_accel_Scale.value` (default -1.2; the iter-38 text mistakenly gave `0x125d60`); angle bookkeeping `0x15961` exact: `L = ac - (aa+ab+turned)` -> `0x2a9720`, `R = (aa-ab-turned) - ac` -> `0x2a971c` with 0-360 azimuth wrapping; shift `0x15ceb`: `x + (int)((|(int)R| < |(int)L| ? -R : L) * scale)`; scale `0x15bd7`: `|Scale|`, times `speed/600` when `Scale < 0`, never below `|Scale|`. Draw gate `0x8f3a/0x8ee3` (df_accel_Draw: 0 off, 1 always, 2 demo or other player's view, 3 own view only, 4 always even without the HUD-allowed test) and `0x8e9c` (HUD allowed unless levelShot / !cg_draw2D / intermission / dead / scoreboard (global `0xebe58`, ASSUMED = `cg.showScores`, offset not verified) / spectator / third person); `0x15f83`: needs a non-zero offset and (outside demos) a held movement key. Mode 0 draws the crosshair copy; modes 1/2 draw the glyphs `O` / `+` (label colour) plus a fixed `+` (font colour), colours = `g_color_table[(cvar & 15) % 10]` with alpha `df_chs2_FontTransparency`.
oDFs: new cvars `df_accel_Draw/Mode/OffsetX/OffsetY/FontSize/Scale/AdjustMaxSpeed`, `df_chs_UsePredicted`, `df_chs2_FontColor/LabelColor/FontTransparency/FontShadow` (defaults from the DeFRaG table); `CG_DF_AccelFrame` + `CG_DF_DrawAccel` called from `CG_Draw2D` (always, independent of `df_hud`). NOT ported: the percentage state and `SPEED:/PERCENT:` log (`0x1584c`, `0x157f8`, `df_accel_Output`, only consumed by CHS widgets / the log), the ghost players (`0x13e70`/`0x13eb1`, DeFRaG ghost system), the jump history logger (`0x16513` family, `df_accel_HistoryResetSpeed`). Default `df_accel_Draw 0` = invisible. Syntax-checked, visually untested. Revert: remove the two calls in `CG_Draw2D` (cg_draw.c) and `cg_dfaccel.c` from CMakeLists.

## Iter 122 — df_accel_Output
Storage 0x126014 (default 0). In `0x1584c` after the state latch: `if (df_accel_Output && latch) { CG_Printf("\n"); CG_Printf(SPEED fmt 0xc3f0, lc,fc,start, lc,fc,cur, lc,fc,hist); CG_Printf(PERCENT fmt 0xc3ba, lc,fc,accelPct, lc,fc,speedPct); }` (lc = df_chs2_LabelColor `0x127328`, fc = df_chs2_FontColor `0x127548`; formats are copied into scratch buffers with strncpy first — no semantic effect). `df_accel_HistoryResetSpeed` (0x125ac4, default 100) is read only by `0x164d6` (stores pos/vel/time into a history record; sets flag +32 when `0x825f(vel) < cvar`), called from jump-history logger `0x16513`.

## Iter 123 — jump-history logger (`0x16513`) DECODED + PORTED
Called at the end of `0x15c24` as `0x16513(&pos, &vel, cg.time)`. Record R at `0x2a95f8` (2790904): +0 pos[3], +12 vel[3] (last ground state), +24 time (0 = none), +28 prev ground flag, +32 reset flag, +36 prev `cg.nextFrameTeleport` (global 958740 = time-8), +40 ring cursor, +44 maxDist, +48 maxHeight, +52 maxSpeed, +56 maxAccel, +60/+108/+156/+204 rings[12] of distance/height/speed/accel%. `ground = 0x1607e(pos, 5.0)` (identical to `0x1558d`: box -15..15 x -24..32, 5 below, mask SOLID|PLAYERCLIP|BODY). Cases: prev&&!ground -> `0x1648f` (if +32: clear rings+cursor, +32=0); !prev&&ground -> `0x16382` (landing: cursor=(cursor+1)%12; dist=|Δxy| to R.pos; speed=|vel xy|; accel%=`*(2791268)` = dfAm.accelPct; maxima updated unless `cgs.clientinfo[cg.clientNum].team==TEAM_SPECTATOR`); !prev&&!ground -> `0x162c2` (needs time!=0 and +36==0: height = pos.z-R.z maxed into ring[1][cursor]; maxHeight/maxDist/maxSpeed updated); finally if ground || (!teleport && R.teleport): `0x164d6` stores pos/vel/cg.time and, if +32==0, sets +32 = (|vel xy| < df_accel_HistoryResetSpeed). `0x160ce` = fmax, `0x825f` = hypot xy. Display: `0x1601c(type,buf)` (CHS items 140-143 -> types 2,3,0,1): iterate i=0..11, idx=(i+cursor+1)%12, append `"%s %4i"` of (int)ring[type][idx] when non-zero; items 145-148 print maxSpeed(+52)/maxAccel(+56)/maxDist(+44)/maxHeight(+48) with the item's %.Nf format.
