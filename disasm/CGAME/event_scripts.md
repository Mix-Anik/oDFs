# df_script_onMapLoad / onJoinTeam / onRespawn (cgame 0x1b2e, events from 0x1c8b)

Evidence: qdec of `0x1b2e`, `0x1c8b`, `0x1ac7`; strings `exec %s.cfg\n`, `team_red/blue/spect/free`, `exec respawn.cfg\n`; mapname string global `0x11d2bc` (= the `levelshots/%s.tga` argument); cvar storage `0x11b764/0x11b874/0x11b984` (+12 = `.integer` at `0x11b770/0x11b880/0x11b990`).

Event word `0x11d280` (built per snapshot transition by `0x1c8b(out, old, new)`; tested with `0x1ac7(mask)`):
- no previous snapshot -> `0x11`; `snapFlags` SERVERCOUNT bit changed -> `0x13` (map load / new server).
- otherwise (event `0x1` not set): `persistant[PERS_TEAM]` changed -> `0x14`; `persistant[PERS_SPAWN_COUNT]` changed -> `0x10`.
Event `0x10` (respawn) dispatches `0x1b2e`, which — unless playing a demo — runs: if event `0x1` and `df_script_onMapLoad` -> `exec <mapname>.cfg`; unless following (`pm_flags & PMF_FOLLOW`): if `df_script_onJoinTeam` and `persistant[PERS_SPAWN_COUNT] == 1` -> `exec team_red|team_blue|team_spect|team_free.cfg` by `PERS_TEAM` (1 red, 2 blue, 3 spect, else free); if `df_script_onRespawn` and team != spectator -> `exec respawn.cfg`. (It also resets the stats accumulators `0x4370` and copies two cg words; not ported.)

**Ported** (iter 84): `CG_DF_ScriptEvents(old, cur)` in cg_defrag.c, called from cg_snapshot.c (`CG_SetInitialSnapshot` with old = NULL, and before `CG_DF_SnapshotTransition`); cvars `df_script_onMapLoad/onJoinTeam/onRespawn` (default 0 = off, archived). Behaviour change: none unless a cvar is set. Revert: remove the two calls in cg_snapshot.c and the cvar rows.

## df_sound_flagGrabbing / df_sound_leadChanges (cgame 0x26e03 = CG_CheckLocalSounds) — iter 85
Same function as vanilla `CG_CheckLocalSounds` with two gates: the flag-pickup sound (`youHaveFlag`, team gametypes) plays only if the client has not detected a DeFRaG server (`0x11d298` = `defrag_vers` non-empty) **or** `df_sound_flagGrabbing != 0` (default 0 = muted on DeFRaG servers); the lead-change sounds (`takenLead`/`tiedLead`/`lostLead`) additionally need `df_sound_leadChanges != 0` (default 1) and `!cg.warmup`. **Ported** in cg_playerstate.c (+ cvars in cg_main.c). Behaviour change: on oDFs servers (`defrag_vers` set) the flag-pickup sound is now muted by default in team gametypes — revert: `df_sound_flagGrabbing 1` or drop the added condition.

## df_player_Sprites (cgame 0x26191 = CG_PlayerSprites) — iter 86
Vanilla `CG_PlayerSprites` (eFlags EF_CONNECTION 0x2000, EF_TALK 0x1000, awards 0x8000/0x8/0x40/0x10000/0x20000/0x800, friend icon) with three DeFRaG differences: (1) the whole function is skipped when `df_player_Sprites` (default 1) is 0; (2) the connection-interrupted sprite blinks (`sin(cg.time / 350) > 0`) instead of being solid; (3) the friend (team) icon is not drawn on DeFRaG servers (`0x11d298` = defrag_vers detected). **Ported** in cg_players.c. Behaviour change on oDFs servers: no friend icon in team games and a blinking lag icon — revert: delete the `defrag_vers` early-return and the `sin` test. (The awards medal order/flags otherwise unchanged.)

## df_mp_NoDrawRadius — interference no-draw radius (cgame 0x9c47 / 0x9bdd / 0x9c12; CG_AddCEntity 0x1f222 and `0x8fa9`) — iter 87
`0x1f222` is `CG_AddCEntity`: ET_PLAYER -> `0x8fa9` (hide test: `0x9c47` || `0x14633(clientNum)` || `0x10912(clientNum)`; the last two are demo/tracking hide lists, not ported) then CG_Player; ET_MISSILE -> `0x9c47` then CG_Missile. `0x9c47(cent)`: never for the viewer's own client; if the distance viewer -> `cent->lerpOrigin` is `< |df_mp_NoDrawRadius|` (default 200) and `ps.stats[14]` (the server's `df_mp_InterferenceOff` value) has bit 0 (players) / bit 1 (missiles) — with bit 2 meaning only other-team clients — the entity is not drawn; with a NEGATIVE radius players are instead drawn translucent (`currentState.powerups |= 16`). Local entities (explosions, `0x9cf3` in the LE loop `0x20dab`) use the same test on an owner stored in `le->color[0]` — not ported (needs the owner tag, see the ghost-sprite note). `df_player_SmokeTrails` (`0x20e2c`/`0x79ea`, value cvar `.value` passed to `0x9082` and to the LE smoke-puff function `0x20a38`) not yet decoded.
**Ported** (`CG_DF_HideForInterference`, cg_defrag.c; calls in cg_ents.c). Behaviour change: with the default server value `df_mp_InterferenceOff 3` other players/missiles within 200 units of you are no longer drawn on oDFs servers. Revert: set `df_mp_NoDrawRadius 0` (client) or remove the two calls in cg_ents.c.

## df_player_SmokeTrails (cgame 0x9082 / 0x9038 / 0x9154, LE loop 0x20dab) — iter 88
Value `N.MM` (default 0 = off): `N` = seconds the viewer's own smoke trail lasts (a puff at the viewer's origin whenever it changed since the last puff, tag 903), `MM` hundredths = seconds the trails of all player entities in the snapshot (tag 901) and of playing ghosts (tag 902, ghost pos `cent.lerpOrigin`) last. At most one update per 25 ms (`next = time + 25`). A puff (`0x9038`) = vanilla `CG_SmokePuff(origin, vel0, radius 4, rgb 1, a 0.66, duration 1000*s, start/fadeIn = cg.time, flags LEF_PUFF_DONT_SCALE, cgs.media.smokePuffShader)` with `leType` changed to **LE_FRAGMENT** (3) and the tag stored in `color[0]` — the stationary fragment branch of `CG_AddFragment` (`0x20628`) then keeps the sprite and sinks it during its last second. `0x9154` (called in the LE loop right before the fragment handler) expires a tagged puff at once (`endTime = time`) when its share of the value is 0. Verified from the dispatch table at data `13120` (idx 1 explosion `0x20a38`, 2 sprite explosion, 3 fragment `0x9154` + `0x20628`). **Ported**: `CG_DF_SmokeTrails` (called at the end of `CG_DF_GhostFrame`), `CG_DF_SmokeFragmentPre` (cg_localents.c), cvar `df_player_SmokeTrails`. Revert: remove the call in `CG_DF_GhostFrame` and in cg_localents.c. Off by default. Note: `color[0]` tagging is also how DeFRaG tags explosion owners (`0x9cf3`) — still unported.

## df_hud_videocapture_* (cgame 0x1ce20 = CG_Draw2D selector, 0x3387) — iter 97
`0x1ce20`: with `df_hud_videocapture_enable` (default 0, not archived) the whole 2D draw is replaced by `0x3387`, which draws only the run timer (`0x1024(elapsed ms)`, only while it is non-zero) as plain text at `(df_hud_videocapture_x, _y)` (default 320,240): cell size = `fontsize` clamped 4..32 (default 16), colour = `g_color_table[fontcolor]` (0..7, default 7), `fontshadow` (default 1), `fontjustify` 0 centre (x - len*size/2, y - size/2) / 1 left / 2 right (x - len*size). The other 2D selector branches seen there: DeFRaG HUD (`0x2a12`) when `df_hud` is set, else the vanilla 2D (`0x1cd86`), then the per-frame updaters `0x79ac`. **Ported** (`CG_DF_DrawVideoCapture`, cg_dfhud.c; early-out in `CG_Draw2D`). The timer is read from `ps.stats[7]/[8]` when `stats[12]&2` (plain form only — encoded times of listen servers are not decoded). Behaviour change: none unless `df_hud_videocapture_enable 1`. Revert: remove the early-out in CG_Draw2D.

## Explosion owner tag + LE no-draw test (cgame 0x2bca9 = CG_MissileHitWall, 0x1dfc9 = CG_MakeExplosion, 0x9cf3) — iter 98
`0x1dfc9` is vanilla `CG_MakeExplosion` (colour = 1.0 each). DeFRaG's `CG_MissileHitWall` then overwrites `le->color[0]` with the **owner client number** for grenade (4), rocket (5), plasma (8) and BFG (9) explosions (railgun already stores the client colour there; machinegun/shotgun/lightning unaffected). This tag is what `0x9cf3` reads: for `LE_EXPLOSION` / `LE_SPRITE_EXPLOSION` it applies the missile rule of `df_mp_NoDrawRadius` (`stats[14] & 2`, `& 4` = other team only) — the viewer's own explosions are never hidden. It is also what the ghost recorder's `SelfMissilesOnly` filter reads (`0x11d58`, `eType`-less local-entity list walk: types 1/2, owner `(int)color[0]`). **Ported**: tag in cg_weapons.c; `CG_DF_HideLocalForInterference` (cg_defrag.c) called for both explosion types in the LE loop. Unported: LE type 7 (`0x208ed`, also gated by `0x9cf3`; type not identified), the ghost sprite packet (next). Revert: remove the tag lines and the two checks.
