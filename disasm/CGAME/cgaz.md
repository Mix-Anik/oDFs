# CGAZ — `0x1a57a` (called from the DeFRaG HUD frame `0x2a12` as `0x1a57a(df_hud_cgaz, df_hud_cgaz_opacity, df_hud_cgaz_ypos)`)

Decoded with `disasm/tools/qdec.py cgame.dis 1a57a` (bytecode -> pseudo-C; **constants print in decimal**). 322 statements, ~1650 bytes.
Arguments: `l1ec` = flags (`df_hud_cgaz`, `0x119ac0`, default 0), `l1f0` = opacity (float, `df_hud_cgaz_opacity` `0x1199ac`, default 0.5), `l1f4` = y (`df_hud_cgaz_ypos` `0x1198a0`, default 256).
Flag bits: 1 = main CGAZ, 2 = big speed readout, 4 = skip the accel bar, 8 = skip tape + arrow, 16 = skip the optimal-angle bars.

Functions: `0x1d161(x,y,w,h,color)` float FillRect with whiteShader, `0x1d12a` CG_AdjustFrom640, `0x1d330` CG_DrawStringExt, `0x1d514` CG_DrawStrlen, `0x3124a(a,b)` = wrap(a-b) to [-180,180], `0x2f3f5` = tan(deg) (sin/cos), `0x2f6c7` = fabs, `0x3086a` = VectorLength, syscalls 105 atan2, 107 floor, 111 acos.

## Colours (data)
`0x2688` white {1,1,1,1}; `0x2698` {0.5,0.5,1,1}; `0x26a8` {1,0.5,0,1}; `0x26b8` accel {1,0,0,0.8}; `0x26c8` 4 tape colours {1,1,.5,.5},{0,1,.5,.5},{0,0,.5,.5},{1,0,.5,.5}; `0x2708` two charset texcoord sets {0.4395,0.5,0.498,0.5586}, {0.373,0.5,0.4316,0.5586}; `0x2728` 8 optimal-bar colours {1,1,0,1},{0,.25,.25,1},{0,1,0,1},{.25,.25,.25,1},{.25,.25,.25,1},{0,1,0,1},{0,.25,.25,1},{1,1,0,1}. The alpha of white/{.5,.5,1}/{1,.5,0} is `min(2*opacity,1)`; tape/optimal alphas and the accel colour are multiplied by `opacity`.

## Behaviour
Exit if `!cg.snap` or `cg.hyperspace`.
1. **bit 2 – speed readout**: `s = va("^%d%4.0f", 7, floor(xyspeed))` drawn with CG_DrawStringExt at x = `640 - strlen*32 - 5*24`, y = `480 - (int)(1.5*2.5*32)` (=360), chars 32x48, shadow; then `va("%0.01f^3u/s", xyspeed-floor)` **minus its first character** at x = 520, y = `480-(int)(1.5*2.375*32)` (=366), chars 24x36.
2. If !(bit 1) return. **Accel bar** (if !(bit 4)): `ps` = predictedPlayerState unless demo/follow/nopredict/synchronousClients, then nextSnap/snap ps. `acc = (|v_xy| - |prev v_xy|)/(commandTime - prevCommandTime) * 256` (x0.1 when on ground), cached while commandTime does not advance; bar from the crosshair edge (`320 ± cg_crosshairSize`, y 232, h 16, width = acc, negative to the left), tick marks at ±81.92 (y 236, 1x8).
3. View: `halfFov = fov_x/2`, `tanHalf = tan(halfFov)`, `yaw = predicted viewangles[YAW]`, `base = yaw (+ 45*movementDir if (stats[13] & 27) || defrag_vers == 0)`. Screen x of angle `a` = `320 * tan(clamp(wrap(base-a), ±halfFov)) / tanHalf` (+320).
4. **Tape** (!(bit 8)): for `ang = 0..315 step 45` using `yaw`: sector between x(ang) and x(ang+90); if left>=right: when `ang%90==0` fill `(x2+320, ypos+16, x1-x2, 16)` with tape colour `ang/90`; tick `(x1+320-1, ypos+32-h, 2, h)` white, `h = (int)(8*(90-rem)/90)`.
5. **Velocity**: return if `|vx|+|vy| <= 0`. `vyaw = atan2(vy,vx)` in degrees. Arrow (!(bit 8)): `e = wrap(base - vyaw)`, if `e>90` flip=1, `e -= 180`; clamp/project; colour white if `vx*vy != 0` else orange; a 16x16 charset glyph at `(e+320-8, ypos+32)` with texcoord set `flip`.
6. **Optimal strafe bars** (!(bit 16)): `a = speed*pmove_msec/1000` (x10 on ground, and then `|v| *= 1 - 6*dt`); return if `|v| <= speed - a`. `aMin = acos(-0.5a/|v|)`, `aMax = acos((speed-a)/|v|)`, `aMid = |v|>speed ? acos(speed/|v|) : 0` (degrees). Angle list `[vyaw-aMin, vyaw-90, vyaw-aMax, vyaw-aMid, vyaw, vyaw+aMid, vyaw+aMax, vyaw+90, vyaw+aMin]`; for each consecutive pair project with `base`; if left>=right fill `(x2+320, ypos, x1-x2, 16)` with optimal colour i; for i==4 also a 2x12 marker `(x1+320-1, ypos+2)` in `{0.5,0.5,1}`.
