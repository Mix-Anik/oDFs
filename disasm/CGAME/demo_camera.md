## Iter 93 — mode tables resolved (jump tables read with the correct bases)
- **Driver `0x1549d` (table at data `9128`, index = mode)**: 1 -> `0x14921` + `0x152a8`; 2 -> `0x14921` + `0x152e9`; 3 -> `0x14921` + `0x1532a`; 4,5,6,7,9,10,11 -> `0x153ec` (smoothed camera); 8 -> `0x1539f` (camera = the tracked client's own view; also sets the viewed client `0x15280`).
- **Hide list `0x14633` (table `8924`)**: hides the tracked player's body in modes **2 and 8** only.
- **Target modes `0x15040` (table `9084`)**: 4..7: preset from a cvar string (`0x7d59`, "cam x y z p y r ..."), else tracked pos/ang with a third-person offset `0x14741(pos, ang, 0, cg_thirdPersonRange-like float @82944)`, applied immediately (`0x14f96` / `0x14fb5` set all four pos/ang slots, no transition); 8: tracked client's pos/ang; 9: `0x14741(pos, ang, 0.0, 100.0)` (third person at 100 units); 10, 11: `0x14741(pos, ang, 0, range @82944)`; others: copy. A changed target restarts the transition (`+4 = 0`).
- **Aim table `0x14f18` (modes 4..11)**: 4 copy the target vector; 5 = vectoangles of (target - camera) with the old roll; 6 = computed yaw, pitch/roll from the target; 7 = computed pitch, yaw/roll from the target; 8 = full vectoangles; 9,10,11 copy.
- **Third-person offset `0x14741(pos, ang, yawOffset, range)`**: `pos.z += viewheight(cg: 958944)`; pitch clamped to 45 unless `1191188`; the camera is moved back by `range` along the view direction rotated by `yawOffset` (negative forward component `-range*cos/sin`), `+8` z, traced from the eye with a +-4 box (`27287`, mins/maxs at data `9044/9056`; on a hit it is pulled in and lifted by `32*(1-fraction)`), and the angles are recomputed to look at the original eye point (`pitch = -atan2(dz, max(dxy,1))`, `yaw -= yawOffset`). It is a classic third-person chase camera.
- **Modes 1..3 (`0x14921`)**: a free-fly camera moved by the usercmd movement bytes (forward/right/up scaled by `5.0 * (|cvar df_demos_CameraTransitionSpeed|/100) * dt`), angles from mouse; `0x152a8`/`0x152e9`/`0x1532a` then place the camera record from the track data.
Next: port modes 8 (first person), 9..11 (third person) and 4..7 first (`CG_DF_DemoCamera` in cg_dfdemocam.c), modes 1..3 after.

## PORTED (iter 100) — free cameras, modes 1..3 (0x14921 / 0x148f0 / 0x8523 / 0x152a8 / 0x152e9 / 0x1532a)
The 76-byte free-camera object (`2790112`): `+4..+12` pitch/yaw/roll accumulators (initial: 0, ps.delta_angles[1], ps.delta_angles[2]), `+16` position (initially the current view origin), `+28` look angles (initially the view angles), `+40..` axis. `0x8523`: angles = `SHORT2ANGLE((short)(usercmd.angles[i] + delta[i]))`, pitch kept within +-16000 (87.9 deg) by re-biasing `delta[0]`. `0x14921`: position += axis * 5 * (|df_demos_CameraTransitionSpeed| / 100) * dt * {forwardmove, -rightmove, upmove} (up along world Z). Modes: **1** camera = free position + free look; **2** = the tracked client's view position + free look (its body is hidden); **3** = the tracked client's eye origin + free look + the third-person offset (range `cg_thirdPersonRange`). The `df_demos_CamOffset*` offsets are applied to all of them. **Ported** in cg_dfdemocam.c (`DC_FreeUpdate`). Caveats: movement bytes are read as signed (`usercmd_t`), the delta bookkeeping of `0x8523` was reconstructed from the compiled code, not run. Revert: restrict `mode < 1` back to `mode < 4` in CG_DF_DemoCamera.
