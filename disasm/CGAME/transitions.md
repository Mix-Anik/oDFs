# DeFRaG cvar transitions — `df_transitions` (cgame `0x9d7f`, iter 46)

Decoded with `disasm/tools/qdec.py` (pseudo-C in this session; helpers `0x8e4a` frame delta, `0x8285` clamp, `0x8a85` `$var` expansion, `0x2f428` atof, `0x32168` COM_Parse(&p, allowLineBreaks=1), `0x80bf` cvar set with protection, `0x325be` strcmp). Called every frame from `0x798b`.
`df_transitions` (cvar, TEMP, default "") is a list of at most **5** (`0x1458`) cvar NAMES (COM_Parse tokens; the string `"0"` disables the feature). Each named cvar holds a six-token definition `<targetCvar> <from> <to> <rate> <mode> <progress>` (from/to/rate/mode may be `$cvar` references; progress is written back every frame). Per frame (`dt = 0.001 * (cg.time - last)`, the static `last` starts at 0 so the very first call has a huge dt):
- `progress >= 1`: mode 1 -> `progress = 0` (restart), mode 2 -> swap from/to (and their text) and `progress = 0`; mode 0 -> finished (entry skipped).
- If `progress < 1` and all six tokens were present: `step = |rate|/100 * dt` (`0x145c` = 100.0), `rate >= 0`: `progress += step`, `rate < 0`: `progress += step * 1000/(int)|to-from|`; clamp progress to [0,1]; `value = from + progress*(to-from)` (mode 0: exactly `from`/`to` at the ends), clamped between min(from,to) and max(from,to).
- The value is applied with the console command `varMath <target> = <value>` (`"varMath %s = %f"`, `trap_SendConsoleCommand`), then the definition cvar is rewritten with `"%s %s %s %s %s %f"` (target, from text, to text, rate text, mode text, progress) via `0x80bf`.
Related (not ported): `0x7a4e` (demo time limit/seek, cvar `df_demos_Seek`), `varMath` command and `0x80bf` protection rules (`user_*` / `df_user_*` cvars).
## oDFs
PORTED as `CG_DF_Transitions` (cg_defrag.c, called from `CG_Draw2D`); `varMath` does not exist in oDFs, so the target is set directly with `trap_Cvar_Set(target, "%f")`. Differences: the zero-distance case (from == to) uses scale 1000 instead of a division by zero; `$var` expansion handles cvars only (DeFRaG also checks its own variable table `0x8887`). With the default empty `df_transitions` nothing happens. Syntax-checked, untested. Revert: remove the call in cg_draw.c.
