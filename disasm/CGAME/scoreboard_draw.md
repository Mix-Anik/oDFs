# DeFRaG scoreboard draw — cgame `0x668c` (0x11a4 bytes), decoded structure (iter 89; NOT ported yet)

Evidence: qdec of `0x668c` (1212 lines; the repeated `if (df_hud_scoreboard_size.integer) a=10 else a=8` chains collapsed), helpers `0x1d161`, `0x1d25d`, `0x1d28f`, `0x1d330`, `0x663a`, `0x1024`, `0x3265e`, data colours and lit strings.

**Cvars** (storage `.integer` at `1152912` / `1152640`): `df_hud_scoreboard_size` (0/1) selects the character cell **8x10 (0) or 10x12 (1)** (`cw`, `ch`); `df_hud_scoreboard_showSpectators` (default 1) gates the second panel (spectators + "Spectators Info"). Gate: `cg.showScores` (`965976`) must be non-zero, else the function returns 0 (not drawn).

**Helpers:** `0x1d161(x,y,w,h,colour*)` = fill rect (`trap_R_SetColor`, `DrawStretchPic` with the white shader `1130368`, then reset); `0x1d25d(x,y,w,h,border,colour*)` = rectangle outline of that border width; `0x1d28f(x,y,w,h,shader)` = picture; `0x1d330(x,y,str,colour*,shadowMode?,?,cw,ch,maxChars)` = text with `^x` colour codes, a 1-3 px shadow pass first; `0x663a(str,width)` = pad on the LEFT with spaces to `width` (right-align; static buffer); `0x1024(ms)` = time string (`S.mmm` below 60 s, `M:SS.mmm`, '-' prefix when negative); `0x3265e(str)` = length without colour codes.
**Colours** (data): border `5092` = (1,1,1,1); header/row fills `5108` = (.3,.3,.3,.9) and `5124` = (.2,.3,.4,.9) and `5156` = (.2,.2,.2,.9); header text `5140` = (.7,.9,1,1); normal text `5172` = (1,1,1,1); small-text colours `16628` (1,1,1,1) and `16660` (.75,.75,.75,1).
**Strings:** `Player`, `   Score`, `Ping`, `-`, `%i`, `Connecting...`, `Spectators Info`, `Speed Award`, `^7: %i ups`, `:`; server/client strings `sv:%s` / `cl:%s`, `%i.%02i.%02i`, `%s [%s]`, `%s %04i-%02i-%02i %02i:%02i`.

**Row widths** (let `cw` = 8/10, `w(n)=n*... `): the table box is `W = ((cw<<4)+6) + ((cw<<3)+6) + ((cw<<2)+6)` wide x `(ch+6)` high rows (`h = ch + 6`; the name column = `(W-6)/2/cw - 1` chars max). Table origin `x = 320 - W - ch/2` (with the speed-award box: `x = 320 - (W1+W2+W3)/...`), `y = 68`; every row steps `y += ch + 6`.

**Layout** (per frame, in order):
1. Top line (when not a demo): `trap_RealTime`, text `"%s %04i-%02i-%02i %02i:%02i"` with the server name (`1168400`) centred at y=57, cell 8x8, colour `16660`.
2. Header box: fill `5124`, outline `5092`, labels `"Player"` (colour `5140`, left) and `"   Score"`/`"Ping"` right-aligned headers.
3. For each of `cg.numScores` entries (68 B each, `961624`; client `+0`, best time ms `+4`, ping `+8`, `+60` flag, `+64` follow-client): row fill `5108` for the viewed client (`== snap client`) else `5156`; outline; the player's name (`clientinfo[+4]`, 1728 stride base `1017704`) in `5172`; if `ping != -1` ('connected'): icons (flag `+60` -> `1167988` shader; `clientinfo.team == TEAM_SPECTATOR(3)` -> `1167984`; the speed-award client -> `1167992`), a right-aligned time (`0x1024(time)` padded 8) when `time != 0`, else `-`; ping column `"%i"` padded 4 (or `-` for spectators); if `ping == -1`: the label `Connecting...`.
4. When `df_hud_scoreboard_showSpectators` and the spectator list exists (`967072`): a second panel titled `Spectators Info` listing the connected spectators that follow someone (`clientinfo.team == 3 && +64 != -1`): `<spectator name> : <followed name>`.
5. Speed-award box (`967076`): `Speed Award` header and the winner's name / `%i ups`.
6. Bottom-right (`472,456`, 6x8): `"%s [%s]"` with the map-name string and the gametype name (`4800 + gametype*4` table); and `x.xx.xx` version / `sv:%s` and `cl:%s` strings at (520,464) and (520,472) (version `1168028` -> `%i.%02i.%02i`; client version `1.91.31` literal).
Not yet mapped: exact column x-offsets (the `(cw<<4)+6`... chains give: name column `W1 = 16 cw + 6`, score `W2 = 8 cw + 6`, ping `W3 = 4 cw + 6`), the meaning of globals `967072/967076/967080/967084/967088`, shader handles `1167984/8/92`. **Port plan**: new `CG_DF_DrawScoreboard()` in cg_draw/cg_scoreboard replacing CG_DrawOldScoreboard when a new cvar (e.g. `df_hud_scoreboard`, default 1) is on; needs those globals decoded first.

## Mapping completed + PORTED (iter 90)
