# DeFRaG demo seek — `df_demos_Seek` (cgame `0x7a4e`, iter 52)

Per-frame (from `0x798b`). Only during demo playback (`cg.demoPlayback`); cvar `df_demos_Seek` (TEMP, float, default `0.00`; `0x122af0`). `0` -> if a seek was active restore `timescale 1`, clear the state. Otherwise the target is `M.SS` (`a = |seek|`, `M = (int)a`, `SS = (int)(100*(a-M))`, target = `1000*(60*M+SS)` ms of level time, current = `cg.time - cgs.levelStartTime`). `needMove` = seek < 0 ? target < current : target > current (literal reading of the bytecode). While `needMove`: on the first frame save `s_volume` / `s_musicvolume` into `df_user_s_volume` / `df_user_s_musicvolume`, set both volumes `0.0`, set `timescale` to 100 (1000 when `SS == 0`), print `DEMOSEEK: Seeking To Target: %i Current: %i Speed: %i`, remember the state. When no longer needed: with a seek active restore `timescale 1` and the volumes and print `DEMOSEEK: Target Reached: %i`, otherwise print `DEMOSEEK: Target: %i Already Past: %i`; then `df_demos_Seek = 0.00`.
DeFRaG writes timescale through its safe-set routine `0x80bf` (`set`), oDFs uses `trap_Cvar_Set` (timescale is CVAR_CHEAT in the stock engine: during demo playback this normally works only with cheats allowed).
