# DeFRaG "$variable" language (cgame `0x8a85` / `0x8887`, iter 47 — expansion only)

DeFRaG cgame commands/cvars accept `$name` tokens. `0x8a85(buf, size)`: empty -> 0; not starting with `$` -> 1 (unchanged); `$` alone -> 0; otherwise `0x8887` tries, in order: `chsInfo(<id>)` / `chsLabel(<id>)` (prefix compare, text between `(` and `)` parsed by `0x8678`, evaluated with the CHS row builder `0xc320` -> value / label), the **named CHS variables** table (data `0x19f8`, 25 entries `{name, chs item}`; evaluated as item id + 3000 = 3 decimals): date 108, time 109, mapname 115, playername 118, cgtime 171, viewposX/Y/Z 36/37/38, viewposXYZ 45, posX/Y/Z 33/34/35, posXYZ 44, angX/Y/Z 30/31/32, angXYZ 46, velX/Y/Z 20/21/22, velXYZ 47, speedXY 23, speedZ 22, demoname 190, fulldemoname 191; `pstat<NN>` / `bpstat<NN>` (`0x87a8`: snapshot `ps.stats[n]` as number / bit string; stats 7 and 8 read as "0"; **gated by the debug password** `df_debug_OutputPassword`, `0x7eaa`); `space` (" "), `empty` (""), `PreviousPlayerNum`, `NextPlayerNum`, `PreviousTeamPlayerNum`, `NextTeamPlayerNum` (`0x7fd5`, spectator follow targets); when none matches, the cvar called `name` is read. Result: non-empty -> usable.
Other members of the language (decoded structurally only, NOT ported): commands `varMath` (`0xa4cc`, expression evaluator, 254 stmts), `varCycle`/`varCycleOnce` (`0xa9ab`/`0xa9b3` -> `0xa897`), `varJoin` (`0xa9bb`), `varFormat` (`0xaaab`), `varCommand` (`0xa42d`), `varSave` (`0xafda`), set through `0x80bf` (cvar write with protection rules: names starting `user_`/`df_user_` etc., `varMath` log), plus `displaymessage`, `savepos`, `read`, `info`, `help`, `ghost`, `replay`, `resetjumpmeter`.
## oDFs
PORTED: `CG_DF_ExpandVar` (cg_dfchs.c) — everything except pstat/bpstat and the player-number variables; now used by the CHS combo tokens and by `df_transitions`. Syntax-checked, untested. Revert: restore the plain `$cvar` lookup.


## Iter 48 — `varMath` PORTED
`0xa4cc`: `varMath <var> <op> <value> [<op> <value> ...]` (pairs from argv 2, at most 25 args), `$` expansion on every argument (`0x8a85`), operators `+ - * / % =` evaluated left to right on the running result (initial = the variable's current value). Classification: a string operand (contains a letter or a space; the value also when empty or `<0>`) switches `+` to concatenation (`"%s%s"`; value `<s>` appends a single space) and `=` to assignment (`<s>` -> a space, `<0>` -> empty); otherwise four candidate results are computed — float/float `r48`, float/int `r4c`, int/float `r50`, int/int `r44` (`/` needs both float and int divisors non-zero, `%` only int) and the one matching the operands' '.'-flavour is printed with `%.4f` or `%i` (`=` clears the left operand's float flag). Errors: `*** Error - missing operator`, `missing value`, `invalid operator: %s`; `varMath ?` (or no argument) prints the usage block (strings at `0x9e..`). The result is stored with `0x80bf` (safe set: restricted names via `set`, otherwise Cvar_Set, with `ISSUING SAFE/UNPROTECTED VAR CHANGE` log lines) then `0xb0ad` (log dump). oDFs: `CG_DF_VarMath_f` (cg_dfchs.c), command registered in cg_consolecmds.c, result via `trap_Cvar_Set`; the log lines and the protected-name routing are not ported. Syntax-checked, untested. Revert: remove the table entry and AddCommand line.


## Iter 49 — varCommand, varCycle, varCycleOnce, varJoin, varFormat, varSave PORTED
`0xa42d` **varCommand** `cmd args...`: every argument `$`-expanded, joined with spaces, executed as a console command (log `Issuing Command:`). `0xa897(wrap)` **varCycle** (`a9ab`, wrap=1) / **varCycleOnce** (`a9b3`, wrap=0) `var default v1 v2 ...` (up to 25 values): if the variable equals `vK` it is set to `vK+1`; after the last value varCycle wraps to `v1`, varCycleOnce leaves it unchanged; a value not in the list sets `default` (missing default -> `*** Error - missing default value`). `0xa9bb` **varJoin** `var s1 s2 ...`: appends the strings to the CURRENT value (`<s>` = a space, `<0>` clears), up to 25. `0xaaab` **varFormat** `var spec1 value1 [spec2 value2]`: builds `%spec1%spec2` (types found by the first `s`/`i`/`f` letter in each spec) and formats the values (string / `atoi` / `atof`) accordingly (nine type combinations). `0xafda` **varSave** `var file`: appends `set <var> "<value>"
` to the file (FS_APPEND = mode 2) and prints `FILE (<file>) Appended Var:` + the line; errors for missing var/file, empty variable, unopenable file. All are no-ops with `?`/no argument printing their usage block. oDFs: functions in cg_dfchs.c, registered in cg_consolecmds.c; values stored with `trap_Cvar_Set` (no protected-name routing / change-log lines). Syntax-checked, untested. Revert: remove the table/AddCommand entries.

## Iter 50 — savepos, displaymessage, resetjumpmeter PORTED
`0xae76` **savepos [option]** (usage with `?`): reads the cvar named by the cvar `saveposname` (error `... is empty. use: set saveposname <myposname> <options>` when unset), takes the viewed player's origin, velocity (snap ps `+76`) and viewangles (`+196`); option 1 zeroes the velocity, option 2 also the pitch; builds `placeplayer %f x9` (origin, angles, velocity) and issues `set <posname> <that line>` (so `vstr <posname>` teleports; `placeplayer` is cheat-gated server-side), then prints `"<name>" Saved: ( x y z ) pitch yaw ( vx vy vz )`. `0xaf72` **displaymessage `y` `size` `message...`**: joins argv 3.. with spaces (`0x8be8`, max 1023) and calls `0x1c707` = the vanilla `CG_CenterPrint(msg, y, charWidth)` (copy to `cg.centerPrint`, time, y, width, line count). `0x16282` **resetjumpmeter** (any argument -> usage): clears the jump-history logger (`0x1621a`/`0x1624f` on the 284-byte record at `0x2a95f8`) and prints `Jumpmeter histories and maximums stats reset.`; oDFs has no logger, so it clears the jump/distance/highest/longest values of the iter-31 tracker instead. Syntax-checked, untested. Revert: remove the table / AddCommand entries.

## Iter 51 — help / commands / ?, read, df_ndm_timer_aliases PORTED
`0xa30b` **help** (aliases `commands`, `?`): no argument -> the command overview (title, `help/commands/?`, the three columns varCommand/varCycle/varFormat/varJoin/varMath/varSave | info/read/ghost/replay/savepos/displaymessage/resetjumpmeter | arena/placeplayer/respawnpoint/firemissile/stats/svinfo_report/svinfo_summary/df_ndm_timer_aliases, the `Type: \command_name ?` hints, `Defrag for Quake3 v1.91.31`, the planetquake URL; colour digits 1 for headers/footer, 3 for the table); with an argument -> `read system/help/<arg>.txt` (those files ship with DeFRaG's pk3, they do not exist in oDFs). `0xad01` **read** `<file>` (`?` = usage, empty -> `dir docs`): tries `<file>`, `system/docs/<file>.txt`, `system/docs/<file>`, `<file>.txt`; prints a `====` banner, `File: <name>`, the contents in chunks of 1023 bytes (at most 10, `*(5788)`), banner; `*** Error: file [ %s ] not found`. `0x415a` **df_ndm_timer_aliases**: prints the 9-line timer alias list (df, resp, gt mg sg gl rl lg rg pg bfg hook, ammo, health, armor, powerups, holdables). oDFs: cg_dfchs.c + cg_consolecmds.c entries. NOTE `help` and `?` text lists commands that oDFs does not have (`info`, `ghost`, `replay`). Syntax-checked, untested. Revert: remove the entries.

## Iter 53 — `info` PORTED (cgame `0xba1d`)
`info [arg]`: `Players` (`0xb94b`: id | team | name for up to 64 clients; team text `----`/` RED`/`BLUE`/`SPEC`, clean name via `0x326ae`), `StringSubs` (`0xb89c`: table of the 25 named substitutions with their CHS number and current value, plus the list of other substitutions and examples), `debug` (items 899-909 and 999, internal), `?` or an unrecognised non-numeric word (error `*** ERROR: Unrecognized info command: %s` + usage + the 'Special Info Items' list), a `$name` argument (printed as `name : value` when it expands), a number (one CHS item, 3 decimals, as `[%03i] label : value`), no argument (all items 1..329, blank line every 10). Uses the CHS item builder `0xc320`. oDFs: `CG_DF_Info_f` (cg_dfchs.c) + command table; items without an oDFs implementation print nothing. Syntax-checked, untested. Revert: remove the entries.

## Iter 105: var-change log `0xb0ad(name, old, new)` (df_varHelpers_DrawOutput)
Cvar value at `0x122bf8`-style address `1184932` (0x121498+12). Called after the safe-set `0x80bf` by varMath (`0xa893`), varCycle (`0xa9a7`), varJoin (`0xaaa7`), varFormat (`0xacfd`). Switch on the cvar (table `0x16a4`): 0 = no output; 1-4 prints `^7[ ^<c>name ^7] Old Value = ^<v>old ^7New Value = ^<v>new`; 5-8 prints `^<c>name ^4--> ^<v>new`; colours: 1/5 white/white, 2/6 df_chs0, 3/7 df_chs1, 4/8 df_chs2 (name = FontColor, values = LabelColor). Ported: `CG_DF_VarSetLogged` in cg_dfchs.c (replaces the four trap_Cvar_Set calls); cvar df_varHelpers_DrawOutput default 0 (ARCHIVE). Revert: change the calls back to trap_Cvar_Set. `df_ghosts_DrawOutput` (`0x125788`) is the ghost analogue.
