# DeFRaG cgame ghost subsystem — survey (iter 74, structure only, NOT ported)

Evidence: qdec of cgame `0x13e09`, `0x13dc3`, `0x13a4a`, `0x13b9a`, `0x13913`, `0x13979`, `0x139df`, `0x13e70`, `0x13eb1`, `0x118ae`, `0x118f6`; strings in the lit segment. Everything labelled "likely" is inferred from call shape only (NO SPECULATION: unverified).

## Storage
- 5 ghost slots, stride **313712 bytes**, base **1221300** (`0x12a1b4`-ish); per slot: `+0` ghost file/name string (copied from the command's name field), `+164` state (0 none, 1 = ?, 2 = recording/active — `0x13e70` scans for `state == 2 && *(slot+312216) != 0` = "the live ghost" used by `0x1a265` as the replay camera target), `+168` record counter, `+180 + 624*i` per-sample records (624 B each; `+4` = origin vec3 as read by `0x13eb1`).
- Cvars (35, `cgame_cvar_table_full.md` "Ghosts"): `df_ghosts_*` (Command, FileExtension, DrawOutput, AutoMode, AutoModeMP, NoDrawRadius, LiveAmmo, CheckPVS, SelfMissilesOnly, Sprite*, Miniview*), `df_ghost1_*` / `df_ghost2_*` (Play: Loop CameraMode DrawMissiles DrawPlayer Timescale; Record: View Interval FileFormat).

## Console command `ghost` (cgame command table, handler `0x13e09`)
`0x13e09` -> `trap_Argv`-style fetch of the whole line (syscall 9, 128 bytes) -> `0x13dc3` -> `0x13a4a(line, &cmd)` parser + `0x13b9a(&cmd, 7)` executor.
- Parser `0x13a4a`: first token must start with `#` (else the help text `0x138f2`): `#all`, or `#N` (N-1 = slot index, 0..4); then the command word from the table at data `8380`: **0 none, 1 stop, 2 record, 3 play, 4 demo** (count word `8404` = 5); the remaining text (up to 128 bytes at cmd+16) is the optional file name (`?` = help). Errors: "^1GHOST --> INVALID COMMAND: %s", "INVALID INDEX: %i", "Use #index to specify ghost number", example "^5Example: ^2ghost #all play".
- Executor `0x13b9a`: for each addressed slot (all = 0..4; flags mask adjusted for `stop`/`play`): builds the file name with `0x118ae` / `0x118f6` (default name `"$mapname_ghostnum"` -> `<base>NN` with a 2-digit slot number via format string at lit `48152`), then per command: none -> `0x139df`, stop -> `0x13913`, record -> `0x13979`, play/demo -> chooses by `*(1221240)` mode (1..8, table at data `8852`) between `0x13913` / `0x13979` / `0x139df`. Ghost start helpers: `0x11958` (likely load/start from file), `0x11a0a` (likely record start), `0x110ff`, `0x11b8a`, `0x10909(mask, n)` (likely "is allowed in this mode" flag test), `0x13721` (status/print line).
- `0x13eb1(cam, outVel)`: velocity of the ghost between its two latest samples: `vel = normalize(posB - posA) * (1000 * |posB-posA| / dtMs)`; used by the replay camera target (`0x1a265`).

## Iter 75 — ghost file I/O and frame layout (qdec of 0x11958, 0x11a0a, 0x11b8a, 0x111be, 0x111f4, 0x1123b, 0x11786, 0x1154b..0x1168b, 0x116d3, 0x110ff, 0x11046)
Slot fields (stride 313712, base 1221300): `+128` file handle, `+132` file length, `+136` frame count (= (length-24)/624 *4?? — literal: `((len - 24) / 624) << 2`, the shift is in the code), `+140` header magic/format, `+144` header version, `+148` 16-byte header string, `+164` state (0 idle, 1 recording, 2 playing), `+168` playback cursor, `+180` frame buffer **312000 B = 500 frames x 624 B**, `+312188` flag set to 1 on successful load, `+312192` / `+312216` mode words (3 -> `0x11046` var snapshot, 15/16 -> `0x110ff` restores), `+312224` (728 B) and `+312952` (760 B = **10 monitored-variable records x 76 B**: name[64] + float cur at +64 + `+68`/`+72` original/saved), `+320` set to 1 on load.
**File**: path = `<dir>` + name + `.` + `df_ghosts_FileExtension` (format `"%s%s.%s"` built from `0x8e22/0x8e03` helpers and a default name `$map_$-route_$gt_$phys_$-mode`), opened with `trap_FS_FOpenFile(path, &f, FS_WRITE=1 | FS_READ=0)`. 
- Header (24 B): `int format` (writer stores the data word at `8352` = 1; reader rejects `format > 1` — "unsupported version"), `int version` (writer stores **1016** = `o3j_version`), `char[16]` (first 16 chars of the string returned by `0xd6c(0)`, run through `0x32784(.., "...")`; not verified what it is). The read path also reads a leading `int == 1` marker (`0x111be` writes a packet-type int the same way, so this is packet type 1 = header).
- Then a packet stream: `int type` + body. First packet of a frame must be type **2**; type **0** or **7** end the stream/frame; unknown type -> error "Bad Packet Type ( %i ) in Snapshot ( %i )". Types (switch at data `8468`, handlers):
  - 2 (`0x1154b`): `int` at frame `+0` (the frame time).
  - 3 (`0x1156b`): vec3 at `+4` (origin) and vec3 at `+16` (angles).
  - 4 (`0x1159a`): `+4` vec3, `+16` vec3, ints `+136`, `+140`, `+28`, `+32`, `+36`, then `+40` (48 B) and `+88` (48 B) — full player state (stats/ammo-sized blobs; field meanings not decoded).
  - 5 (`0x11624`): one of up to 10 per frame (index counter): at `frame+144+32*i`: `+24` int, `+28` int, vec3 at `+0`, vec3 at `+12` (missile-like entity: position/velocity or origin/angles + two ints); extras beyond 10 are read and dropped.
  - 6 (`0x1168b`): up to 10 per frame at `frame+464+16*i`: vec3 + one 4-byte value (sprite / marker).
  - 8 (`0x116d3`): variable record: `char[64] name`, `float value`; matched by name against the 10 monitored-var slots (set value at `+64`), else put in the first free slot (and its current cvar value read into `+72`).
- On load (`0x11a0a`): memset slot parts, read format int, header, then `0x11786` reads up to the buffer; success needs `frame[0] != 0`, then `cursor=0, state=2`. Errors print `^1GHOST: [ %s ] --> ...`. `0x11b8a` = close (FS_FCloseFile, clear buffer, state 0). `0x11958` = open for record: writes the header, `state=1`.
Not yet decoded: what the recorder samples each frame (writer calling `0x1154b..`), playback driver (where `+168` advances), rendering.

## Iter 76 — recorder decoded (qdec of 0x12785, 0x12620, 0x114a2, 0x1127a, 0x112b1, 0x11343, 0x113bf, 0x1141c, 0x11bca..0x11d58)
- Per frame `0x79c1` -> `0x12785(cg.time)`: for every slot with `state == 1` (recording) call the sampler `0x12620(slot, time)`.
- Sampler `0x12620`: needs the file open; `0x11bca` (if `*(958740)` — a cg flag next to cg.time, e.g. a "teleported / new snapshot" style flag — set `slot+312180 = 1`), `0x11bf5` (record-level 3 only: refresh the 10 monitored-var values from their cvars + `0x10fff`). Sampling is rate-limited: proceeds only when `slot+312184 (last time) + slot+312196 (RecordInterval) <= time`. Then: zero the 624-byte frame at index `slot+168`, `frame[0] = time`, fill with `0x11c4d` (player state), `0x11cd8` (missile entities), `0x11d58` (marker sprites), `0x11bd7` (`frame+140 = slot+312180`, then clear that flag = "discontinuity" marker), and if `slot+312200 >= 1` (RecordView) overwrite `frame+4` / `frame+16` with the **view** origin / angles (`960212` = refdef.vieworg, `960556` = refdefViewAngles) with `origin[2] -= data[8372]` (a float constant, eye-height offset; value not read) and `frame+136 = 0`. Write it out with `0x114a2`, advance the circular index `0x123d3(idx, 500)` (a wrap), `slot+312184 = time`.
- `0x114a2(slot, idx)`: writes packet type 2 + `frame[0]` (time), then by `slot+312192` (RecordFileFormat 0..3; table at data `8460`): 0 = type 3 (pos/angles only), 1 = type 4 (full state), 2 = type 4 + type 5 (missiles) + type 6 (sprites), 3 = all that + type 8 (changed monitored vars, written only when value != last-written `+68`); always ends with packet type 7 and `slot+136++` (frame count).
- `0x11c4d` frame fill (player state, cgame globals relative to cg.time=`958748`): `+4` vec3 = `958800` (= `cg.predictedPlayerState.origin`, +52), `+16` vec3 = `958932` (= ps.viewangles, +184; matches the vanilla playerState_t layout), `+136` = `*(958792) & 1` (= ps.pm_flags & PMF_DUCKED), `+28/+32/+36` ints = `959440 / 959448 / 959444` (cg fields, 700/692/696 bytes after cg.time — meaning not identified), `+40` (48 B) = copy of `959748`, `+88` (48 B) = copy of `959700` (consecutive 48-byte blocks — consistent with the two `lerpFrame_t` (legs, torso) of a `playerEntity_t`, i.e. animation state; NOT verified), `+80/+128` zeroed.
- `0x11cd8` missiles (type 5): walks `cg.snap->entities[]` (`*(851180)+516`, stride 208, count at `+512`; entity -> `cg_entities` at `105672 + 728*n`); keeps entities with `eType == 3` (ET_MISSILE) — and, if `*(1221260)` (df_ghosts_SelfMissilesOnly) is set, only those whose `+168` (owner / clientNum field) equals `*(958920)` (the client number) — up to 10: `+24` = entity `+0` (number), `+28` = `+192` (weapon / pe field), vec3 `+0` = entity `+704`, vec3 `+12` = entity `+36` (trajectory base?).
- `0x11d58` sprites (type 6): walks the doubly-linked local-entity list (head `2977132`), keeps entries with type 1 or 2 (`+8`) whose owner (`+108`) matches (same SelfMissilesOnly rule), up to 10; records `+220` vec3 and a code 4 / 5 / 8 / 9 chosen by comparing the entity's shader/model `+264` with four cached handles (`1130816`, `1130812`, `1130804`, `1130820` — likely explosion / smoke sprites; not identified).
Still undecoded: playback (`state == 2`, cursor `+168`), rendering of the ghost player/missiles/sprites, miniview, AutoMode, commands `0x13721`.

## Iter 77 — playback driver mapped (qdec of 0x127af, 0x12421, 0x1344f, 0x12934, 0x11ee4, 0x14029, 0x140b0, 0x140ea)
- Per frame `0x79c1` -> **`0x127af(time, a, b)`** (called with `(cg.time, 1, 0)`): loops over the 5 slots with `state == 2` (playing). `b == 0` (this call) uses the slot's own mode word `+312216`; otherwise the global `1221276`. Steps: `0x12421(slot, time, &slot+172, &slot+176)` advances the cursor `+168` (two indices `+172/+176` = the frames to interpolate between); `0x12934(&l34)` zero-inits a 36-byte render context (`+28 = -1`); if the mode word is non-zero and nothing has claimed it yet this frame, `0x12a10(slot, ctx, time, idx0, idx1, mode)` (size 0x5b6, the **miniview / camera view set-up**); then `0x1344f(slot, ctx, time, i0, i1)` = three drawers `0x13125` (0x1f3 B), `0x13317` (0xc6 B), `0x133dc` (0x74 B) (player, missiles, sprites — role by size/order, not read); `0x11ee4(slot)` (mode words 15/16: apply changed monitored variables to cvars when they differ from the file value, `%i`/`%.3f` format as in the replay VARs). End of data (`frame[0] == 0` at the cursor): by `slot+312220` (PlayLoop): 0 -> `0x139df` (stop), 1 -> stop + `0x13979` (replay: restart), 2 -> wrap the cursor with `0x123bd(idx, 500)`.
- `0x12421`: time-synchronised cursor advance. `slot+312204` is the float play timescale (negative = reverse): it advances while `frame[next].time` is within `(time - slot+312184) * |timescale|`, rewinds for negative, streams further frames from the file ring with `0x11786(slot, idx)` (refill) and wraps with `0x123d3`; honours `df_ghosts_*` flag `1221244`.
- Helpers: `0x14029(slotIdx, outDist...)` = `0x8375(frame.origin, ps.origin, arg)` (distance between a ghost's current origin and the player, for CHS "ghost dist" items), `0x140b0(out, slotIdx)` = ghost origin or a default vec3 at data `8888`, `0x140ea` = "any slot playing" (state at `+164`=2 is read as `1221464` = base + 164).
Remaining undecoded: `0x12a10` (miniview/camera), `0x13125`, `0x13317`, `0x133dc` (draw), `0x12fc5`, `0x134dc`, `0x11fd8`, `0x12199`, `0x12233`/`0x12290`/`0x122ad`, `0x123bd..0x12421` helpers, AutoMode load path, `0x15c24`/`0x15f83` hooks.

## Iter 78 — ghost entity build / draw decoded (qdec of 0x13125, 0x13317, 0x133dc, 0x11fa2, 0x11fd8, 0x11e15, 0x12078)
**Key identification (cross-checked against vanilla struct layouts):** the 624-byte frame stores a *player entity snapshot*. `cg.predictedPlayerEntity` = cgame address `959248` (so `+192/+196/+200` = `currentState.weapon / legsAnim / torsoAnim` = `959440 / 959444 / 959448`, and `pe.legs` = `+452` = `959700`, `pe.torso` = `+500` = `959748`, each a 48-byte `lerpFrame_t`). So frame fields: `+28 = weapon`, `+32 = torsoAnim`, `+36 = legsAnim`, `+40` (48 B) = `pe.torso`, `+88` (48 B) = `pe.legs`, `+4` = origin, `+16` = angles, `+136` = ducked (pm_flags & 1), `+140` = discontinuity flag, `+80/+128` zero. The ghost's own `centity_t` (728 B in DeFRaG; its layout is vanilla up to `pe` (`+452`, ends `+624`) and then `+624` is an extra float (the play timescale used by the animation code), `lerpOrigin = +704`, `lerpAngles = +716`) lives in the slot at `+312224`.
- `0x11fa2(slot, i, j)` = "discontinuity between frames i and j" (`frame[i].+140 != 0 || frame[j].+140 != 0`).
- `0x11e15(slot, time, i, j)` = interpolation fraction between frames i and j: `(time - (frame[i].time + slot.+312184 ...)) / (frame[j].time - frame[i].time)` with the play timescale (`|ts|`); 0 if the frames are equal / unset.
- `0x11fd8` = interpolated pose: `lerpOrigin = lerp(origin_i, origin_j, f)`, `lerpAngles = LerpAngle(angles_i, angles_j, f)`; no interpolation across a discontinuity.
- `0x12078` = build the ghost centity from frame j: pose via `0x11fd8`, `currentState.weapon/torsoAnim/legsAnim` from `+28/+32/+36`; unless (`currentState.number`-ish field `+512` set && timescale >= 0 && no discontinuity) it resets `pe.legs`/`pe.torso` from the frame's blocks (zeroing `animation` pointers `+492/+540`) and `+624 = 1.0`, else `+624 = timescale`.
- `0x13125` (player): `refEntity` zeroed (140 B), builds the centity (`0x12078`), sets `ci` / `clientNum` (`+312392 = *(958920)` = own client number, `+312412 = 0`), computes the distance to the viewer with `0x8375(..., 2)` (2D distance); if it is `< df_ghosts_NoDrawRadius (1221248)` and the render context `ctx+32 == 0`, sets `ctx+4 = ctx+0 = 1` ("too close, hide"). Then by `slot+312208` (DrawPlayer mode 0..4, table `8716`): 0/1 draw the vanilla player (`0x268f2(centity)` = vanilla-shaped CG_Player, then `0x12fc5`), 2 (flag bit 16 ⇒ translucent), 3 (shows only the hidden/inside variant), 4 = draw a marker: refEntity `reType 2` sprite (`shader 1130864`, radius 10, white) via `trap_R_AddRefEntityToScene` (syscall 41). Finally `0x26a50(centity, ...)` if `ctx+8` (shadow/sprite), and the centity is cleared except `lerpOrigin/lerpAngles` (`+312928/+312940`) unless the timescale is negative.
- `0x13317` (missiles/entities, `slot+312212` = DrawMissiles 1 or 2): for up to 10 recorded entities (`frame+144+32*i`) build a centity with `0x12199(...)`; if `0x12290()` then `0x122ad` (extra setup); add via `0x1f3a0(&ent)` (CG_AddCEntity-like) with `ent type 4/5` forced to rocket/plasma trails when the timescale is non-zero, temporarily setting the global at `73972` (likely a "ghost drawing" flag) to 1.
- `0x133dc` (sprites, DrawMissiles == 2): for up to 10 recorded sprites (`frame+464+16*i`): `0x12233` builds a refEntity, then it is added as a translucent (alpha 84) `RT_SPRITE` of radius 51 unless closer than `df_ghosts_NoDrawRadius`.
Still undecoded: `0x268f2`, `0x26a50`, `0x12fc5`, `0x12199`, `0x12233`, `0x12290`, `0x122ad`, `0x1f3a0`, `0x12a10` (miniview), the AutoMode loader and the `0x13721` status print.
Plan: port a ghost module reusing oDFs `CG_Player` (the ghost centity is a vanilla-layout `centity_t`, so recording `cg.predictedPlayerEntity.pe.legs/torso` + weapon/anim fields is directly portable) — decode `0x268f2` first to learn what DeFRaG changed in CG_Player.

## Iter 79 — remaining ghost helpers (qdec of 0x268f2, 0x26a50, 0x12fc5, 0x12199, 0x12233, 0x12290, 0x122ad)
- **`0x268f2` = vanilla `CG_Player(centity_t *cent)`** (clientinfo stride 1728 at `1017704`, `clientNum = cent->currentState.clientNum` (`+168`), three zeroed 140-byte refEntities (legs/torso/head), `CG_PlayerAngles`/`CG_PlayerAnimation`/`CG_PlayerPowerups` shaped calls, renderfx 128 (=RF_LIGHTING_ORIGIN) |256 when `*(95188)==3`...). Unmatched: copy frame j directly.
- `0x12233`: sprite refEntity setup: origin = rec vec3 → `ent+68`, shader `ent+112` chosen by the code in `rec+12` (4/5/8/9 → the four cached shader handles `1130816/1130812/1130804/1130820`; 4..9 only, else 0).
- `0x12290` = "extra missile effects enabled": `*(8348) != 0 && df_ghosts_...(1221252) > 0 && *(1182676) != 0`. `0x122ad`: when such a missile (record code `rec+28 != 10`) has no match in the previous frame (just fired), issues a console command string (format at lit `47753`: position `x y z+24`, a direction from `0x31c8d(angles)`, weapon id and two flags) — i.e. DeFRaG spawns the muzzle/weapon effect for the ghost's fired missile through a client command; not decoded further.

## Iter 83 — ghost missiles PORTED (packet type 5; 0x11cd8 recorder, 0x11343 writer, 0x11624 reader, 0x12199 builder, 0x13317 drawer, 0x1f3a0)
- Recorder (format >= 2): for each snapshot entity that is `ET_MISSILE` (and, with `df_ghosts_SelfMissilesOnly` (default 1), owned by the local client: `currentState.clientNum == ps.clientNum`), up to 10: `{number, weapon, lerpOrigin, pos.trDelta}`; written as packet 5 (`int number, int weapon, vec3 origin, vec3 velocity`) for records with `weapon != 0`.
- Playback: the "to" frame's records are matched by entity number with the "from" frame's; origin is linearly interpolated, and — as DeFRaG literally does (`0x822c` LerpAngle on the `+36` field = `pos.trDelta`) — the velocity is angle-lerped; weapon 10 (grapple) is shown as the rocket (weapon 5). Drawn through `CG_Missile` (`0x1ed2a`) on a zeroed private centity.
- `0x1f3a0` identification: it zeroes `*(103580 + 136*weapon)` around the `CG_Missile` call; `103496 = 105672 (cg_entities) - 16*136` is `cg_weapons[]`, so the field is `cg_weapons[w].missileSound` at +84 -> the ghost missile makes no looping sound (`CG_DF_AddGhostMissile` in cg_ents.c).

## Iter 99 — ghost explosion sprites PORTED (packet type 6; 0x11d58 recorder, 0x1168b reader, 0x113bf writer, 0x133dc / 0x12233 draw)

## Iter 107: status lines `0x13721(slot, index, kind)` and command flags (df_ghosts_DrawOutput)
Executor `0x13b9a(cmd, flags)` is always called with flags 7 (console command and the df_ghosts_Command pump `0x13dd5`); bit 2 = print "command failed", bit 4 = print the success line; `#all` with stop(1)/play(3) clears bits 1+2.
